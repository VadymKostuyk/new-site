# Садиба «Кичера» — сайт на GitHub Pages

Адаптивний сайт садиби в Міжгір'ї, Закарпаття. Проєкт працює як звичайний статичний сайт: HTML, CSS, JavaScript та локальні зображення, без сервера й системи збірки.

## Що є на сайті

- Головний екран і зручна навігація, включно з мобільним меню.
- П'ять варіантів розміщення з початковими цінами, описом, місткістю та зручностями.
- Галереї для кожного варіанта: стрілки, індикатори, свайп на сенсорному екрані та відкриття фотографії на весь екран.
- Підпис під кожним фото; у повноекранному перегляді можна перегортати фото кнопками або стрілками клавіатури.
- Модальне вікно «Детальніше» для кожного номера.
- Послуги, чан із джакузі, додаткові активності, туристичні локації з картами, відгуки, контакти й швидка кнопка дзвінка на мобільних пристроях.
- Оптимізовані WebP-зображення у папці `web/` для швидшого завантаження. Початкові JPG-фотографії збережено; вони використовуються при відкритті фото на весь екран.

## Публікація на GitHub Pages

1. Розпакуйте архів на комп'ютері.
2. Завантажте **вміст папки `sadyba-kychera-site-main`**, а не сам ZIP, у корінь вашого GitHub-репозиторію. Збережіть папки `web/` і всі JPG-фотографії разом з `index.html`, `style.css` та `main.js`.
3. У GitHub відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім натисніть **Save**.
5. Дочекайтеся завершення публікації GitHub Pages та відкрийте адресу сайту.

## Як змінювати інформацію

- **Ціни, початкові описи й зручності номерів:** `index.html` — знайдіть відповідну картку в секції `<!-- Rooms Section -->`.
- **Додаткові описи номерів і підписи до фотографій:** `main.js`, об'єкти `ROOM_GALLERIES` і `ROOM_DETAILS`.
- **Фотографії в галереї:** назви файлів перелічені у `ROOM_GALLERIES` в `main.js`. Для кожного фото має бути JPG-оригінал у корені проєкту та оптимізована WebP-версія з такою самою назвою у папці `web/`.
- **Телефон:** у `index.html` замініть номер у `href="tel:+380677659478"` і видимому тексті. Перевірте всі входження пошуком у редакторі.
- **Туристичні локації та карти:** посилання й підписи розміщені в секції `id="attractions"` у `index.html`.
- **Кольори, розміри та адаптивність:** `style.css`.
